# 墨池 · 日记许愿池

一个国风水墨风格的网页日记与心愿许愿工具：把"写日记"变成一场**投签仪式**，把"回看"变成一次**捞签时光**。

写下心事 → 选签色（墨/黛/朱/青）→ 掷入水墨池，池面泛起墨晕涟漪，签影缓缓漂在水上；日后点签影即可"捞签"回看旧日心迹，并可"焚签"删除。每条签自动附农历、节气与干支落款。纯前端、零依赖、数据仅存本地 `localStorage`，不上传、不联网。

## 快速开始

纯静态单文件应用，两种方式：

```bash
# 方式一：直接双击打开
open index.html

# 方式二：本地服务（纹理图正常加载）
python3 -m http.server 8642
# 浏览器打开 http://127.0.0.1:8642
```

## 功能

- **投签**：写一句话心事，选签色，掷入墨池（`⌘/Ctrl + Enter` 快捷）
- **墨池 Canvas**：池底水墨渐变 + 漂浮云雾 + 掷签墨晕涟漪 + 月影
- **签影漂浮**：池面漂浮近 12 支签，点选捞签
- **捞签弹层**：展示签文 / 公历 / 农历 / 干支 / 生肖 / 节气，支持焚签删除
- **签谱时间轴**：竖排时间轴列全部签，点读
- **农历节气**：内置 `LUNAR_INFO` 表（1900–2100，含边界保护）
- **持久化**：`localStorage` 刷新不丢

## 技术特点

单文件、零依赖、可离线；Canvas 做涟漪，CSS 做漂浮动效，内置查表算法算农历/节气/干支。
